# 🚲 Bike Recondition House Management System (Laravel)

A comprehensive Laravel-based web application to manage bike reconditioning business operations including seller records, buyer details, payment tracking, and inventory management.

## 📋 Features

- **Seller Management**
  - CRUD operations for sellers
  - Contact information tracking
  - Purchase history from sellers
  - Seller payment management

- **Buyer Management**
  - Customer database management
  - Purchase history tracking
  - Contact details storage
  - Buyer payment tracking

- **Payment Tracking**
  - Dual payment system (Seller/Buyer)
  - Payment status tracking (Pending/Completed/Overdue)
  - Payment history and reports
  - Automated payment reminders

- **Inventory Management**
  - Bike stock tracking
  - Reconditioning status management
  - Bike specifications and details
  - Status tracking (In-Recon/Ready/Sold)

- **Reports & Analytics**
  - Daily/Monthly sales reports
  - Profit/Loss calculations
  - Payment summaries
  - Export to PDF/Excel

- **User Authentication**
  - Role-based access control
  - Secure login/registration
  - Password reset functionality

## 🚀 Tech Stack

- **Framework:** Laravel 10.x
- **Database:** MySQL / PostgreSQL
- **Frontend:** Blade + Bootstrap 5 / Tailwind CSS
- **Authentication:** Laravel Breeze / Jetstream
- **Reporting:** Laravel Excel / DomPDF
- **Queue:** Redis (for background jobs)
